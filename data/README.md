# Data Folder

This project uses publicly available Airbnb datasets.

To run the analysis, download the following files:

* `listings.csv`
* `reviews.csv`

From:
http://insideairbnb.com/get-the-data/

Select the Sydney dataset and place the files inside this folder:

```
data/
├── listings.csv
├── reviews.csv
```

These files are not included in this repository due to their large size.
